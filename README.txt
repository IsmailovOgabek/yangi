ROYAL STAY HOTEL — DEMO WEBSITE

How to open:
1. Extract RoyalStay_Hotel_Website.zip.
2. Open the RoyalStay_Hotel_Website folder.
3. Tap/double-click index.html to start the site.
4. Navigate using the top menu. Pages are separate HTML files.
